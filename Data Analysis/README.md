# Data Analysis

## Description

This folder contains the Exploratory Data Analysis (EDA) performed on the Cityflo dataset.

The analysis focuses on understanding the dataset through statistical summaries and visualizations to identify patterns, trends, and business insights.

### Contents

- Data loading
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Data Visualization
- Statistical Insights
- Business Findings

### Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Objective

To explore the Cityflo dataset, identify meaningful patterns, and generate actionable insights that support data-driven decision-making.
