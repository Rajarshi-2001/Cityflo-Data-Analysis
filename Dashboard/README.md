# Dashboard

## Overview

This folder contains the dashboard developed for the Cityflo Data Analysis project.

### Contents
- Interactive visualizations
- Key Performance Indicators (KPIs)
- Business insights dashboard
- Charts and graphs representing important trends

### Objective
The dashboard provides a visual summary of the dataset, helping users understand travel patterns, customer behavior, operational performance, and other key insights derived from the analysis.

### Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly (if used)
